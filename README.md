## 📱 Sobre o Aplicativo
O **ChurchRankingApp** é um Progressive Web App (PWA) moderno e automatizado para cálculo, registro e acompanhamento do ranking semanal de pontos dos adolescentes na Escola Sabatina.

### ✨ Funcionalidades
- **Cálculo em Tempo Real:** Pontuação dinâmica conforme os itens são respondidos.
- **Banco de Dados Local & Histórico:** Salva os envios de cada sábado no dispositivo (IndexedDB e LocalStorage).
- **🏆 Placar & Ranking Geral:** Pódio com medalhas (🥇, 🥈, 🥉), pontuação acumulada e quantidade de participações.
- **Envio Automático via WhatsApp:** Gera mensagem formatada pronta para enviar ao professor ou grupo de líderes.
- **Exportação para Planilhas:** Exporta histórico completo em CSV para controle dos professores.
- **100% Funcional Offline (PWA):** Pode ser instalado no celular Android, iPhone e computador.
